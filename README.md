Entry for the [make.fun competition "Make the AI Judge Feel Proud: A Family Scene"](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2).

The program (`main.ts`) writes one two-line family scene — 273 characters — to `/output/entry.txt`: three generations around Grandma's soup, where the pride is earned inside the scene (Grandma quietly writes Mum's name on the recipe card, then asks for seconds) and never declared. See `DESIGN.md` for why this scene was chosen and how it was picked.

Run it locally with `node main.ts` (Node 22+), or `OUTPUT_PATH=entry.txt node main.ts` to choose the output file. The output is byte-identical on every run.
